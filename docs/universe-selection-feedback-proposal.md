# 수집 유니버스 선정 기준 진단 및 개선 제안 (Universe Selection Review & Roadmap)

> **목적:** 현재 `krx-alpha`의 수집 유니버스 선정 정책([`src/universe/policy.py`](../src/universe/policy.py))의 구조적 한계를 진단하고, 핵심 주장과 코드 실측 근거를 바탕으로 단계별 실행 방안을 정의한다.

---

## 1. 진단 요약 (AS-IS vs TO-BE)

| 구분 | 현행 (AS-IS) | 제안 (TO-BE) |
| :--- | :--- | :--- |
| **기준 시점** | $T-1$ 거래일 일봉 (08:20 고정) | 정규장: $T-1$ 일봉 + 장중 보완<br>애프터마켓: **당일 정규장 실적 (15:30 재선정)** |
| **선정 방식** | 100% 정적 (Static, 하루 종일 유지) | 세션 전환 기반 준동적 (Quasi-Dynamic) |
| **초과 처리** | `SlotBudgetExceededError` (수집 중단) | **거래대금·모멘텀 복합 랭킹 절삭 (Pruning)** |
| **정렬 기준** | 종목코드 오름차순 (`symbol` ASC) | **우선순위 스코어 내림차순 (`score` DESC)** |
| **애프터마켓 타겟**| 전일 주도주 (정규장과 동일 타겟) | **당일 정규장 거래대금/급등 상위 40종목** |

---

## 2. 현행 정책(AS-IS) 핵심 한계 및 실측 근거

### [한계 1] 당일 신규 주도주 누락 (T-1 정적 의존)
* **주장:** 한국 시장의 당일 데이트레이딩 주도주(거래대금 수천억 상한가) 대부분은 장 개시 후 뉴스/수급으로 발생하나, 현재 시스템은 이를 당일 전혀 수집하지 못함.
* **근거:**
  * [`src/orchestration/daemon.py#L122`](../src/orchestration/daemon.py): 08:20 세션 오케스트레이션 시 $T-1$ 기준 `decision_date` 일봉만 스캔.
  * 전일 급등 후 당일 거래량이 급감한 종목은 하루 종일 웹소켓 슬롯을 낭비하고, 당일 신규 상한가 종목은 내일 아침이 되어서야 수집 대상에 포함됨.

### [한계 2] 애프터마켓(15:40~20:00) 타겟 미스매치
* **주장:** 애프터마켓 수집의 본질은 "오늘 정규장에서 가장 뜨거웠던 종목의 시간외 호가/체결 미세구조" 관측이나, 현재는 "어제 주도주"를 시간외까지 그대로 추적함.
* **근거:**
  * [`src/orchestration/daemon.py#L445-L458`](../src/orchestration/daemon.py): 15:40 애프터마켓 샤딩 플래너가 아침 08:20에 쓰인 `candidates.json`을 그대로 로드.
  * 오늘 정규장에서 터진 진짜 대장주의 Nextrade/KRX 시간외 거래(15:40~20:00) 데이터가 완전히 누락됨.

### [한계 3] 슬롯 초과 시 방어 로직 부재 (크래시 위험)
* **주장:** 불장으로 조건 충족 종목 수가 예산을 초과하면, 우선순위 절삭 없이 즉시 예외를 발생시켜 당일 수집 데몬을 정지시킴.
* **근거:**
  * [`src/universe/policy.py#L91-L92`](../src/universe/policy.py):
    ```python
    if selected.height > slot_budget:
        raise SlotBudgetExceededError(f"selected {selected.height} exceeds slot_budget {slot_budget}")
    ```
  * 최종 출력이 `sort("symbol")`로 되어 있어 거래대금이나 모멘텀 강도에 따른 우선순위 메타데이터가 존재하지 않음.

### [한계 4] 유동성 하한선(50억)의 낮은 변별력
* **주장:** `trade_value_100m >= 50.0` (일 50억 원)은 소형 품절주나 잡주가 슬롯에 진입하기에 너무 낮음.
* **근거:** 고빈도 틱/호가 오더북 수집은 틱 단위 체결이 촘촘하고 호가 스프레드가 좁은 유동성 풍부 종목(최소 150억~300억 이상)에서 알파 추출 가치가 발생함.

## 3. 단계별 개선 제안 (Actionable Roadmap)

```
[Phase 1] 랭킹 절삭 & 점수화 (안전망)
   │  - SlotBudgetExceeded 방어 (거래대금 상위 Cutoff)
   │  - selection_reasons 가중치 스코어 부여
   ▼
[Phase 2] 세션 전환 애프터마켓 유니버스 재선정 (핵심 가치 극대화)
   │  - 15:30 정규장 종료 직후 당일 실적 기반 Top 40 추출
   │  - 15:40 애프터마켓 KIS 샤드에 오늘 진짜 주도주 투입
   ▼
[Phase 3] 정규장 장중 동적 스왑 (중장기 고도화)
      - 키움 ka10027 또는 토스 랭킹 연동 (09:30, 11:30 갱신)
```

### [Phase 1] 우선순위 랭킹(Priority Pruning) 도입 (즉시 적용)
* **목표:** 크래시 방지 및 종목 중요도 메타데이터 확보.
* **로직:**
  1. 복합 점수 산출:
     $$\text{score} = \ln(\text{trade\_value\_100m}) \times (1 + 0.5 \times N_{\text{reasons}})$$
  2. 필터 통과 종목 수가 `slot_budget` 초과 시 에러 대신 `score` 내림차순으로 상위 $N$개만 절삭(`head(slot_budget)`).
  3. `candidates.json`에 `rank`, `score` 필드 기록.

### [Phase 2] 세션 전환 시 애프터마켓 유니버스 재선정 (킬러 피처)
* **목표:** 장중 실시간 웹소켓 재연결 위험 없이, 가장 안전한 시점(15:30~15:40)에 당일 주도주로 애프터마켓 타겟 교체.
* **실행 시점:** 15:30 ~ 15:35 (KRX 동시호가 마감 후)
* **수행 절차:**
  1. KIS 또는 토스 REST API(`/api/v1/rankings` or `FHPST01710000`)를 호출하여 당일 누적 거래대금/등락률 상위 종목 수집.
  2. 당일 상한가 및 거래대금 최상위 **40종목**으로 `candidates_aftermarket.json` 갱신.
  3. 15:40 애프터마켓 시작 시 이 갱신된 파일을 로드하여 Nextrade/KRX 4개 샤드에 배정.
* **기대 효과:** 당일 진짜 상한가/테마주의 시간외 가격 형성 및 Nextrade 유동성 틱 데이터를 100% 무손실 수집.

### [Phase 3] 정규장 장중 동적 스캐너 연동 (중장기 과제)
* **목표:** 09:00 개장 직후 터진 신규 주도주를 정규장 장중에 즉시 편입.
* **전제 조건:** 웹소켓 구독/해제 Churn으로 인한 패킷 유실 방지 가드 확보.
* **실행 안:** 키움 `ka10027`(전종목 등락률 순위)을 09:30에 1회 호출하여 하위 20% 저유동성 종목을 당일 급등주로 핫스왑.

## 4. 데이터 계약 및 인터페이스 변경안 (Spec Draft)

### `candidates.json` 스키마 확장안
```json
{
  "rev": 20260916,
  "session": "REGULAR",
  "generated_at": "2026-09-16T08:20:00+09:00",
  "candidates": [
    {
      "rank": 1,
      "symbol": "005930",
      "score": 14.82,
      "trade_value_100m": 5420.0,
      "selection_reasons": ["volsurge", "newhigh60"]
    }
  ]
}
```

### 오케스트레이션 타임라인 (`src/orchestration/daemon.py`)
* `08:20`: $T-1$ 일봉 기반 정규장 유니버스 선정 (`candidates.json`, 최대 90종목).
* `08:50 ~ 15:30`: 정규장 실시간 수집 (LS 웹소켓).
* **`15:31` (신규 훅):** 당일 실적 기반 애프터마켓 유니버스 선정 (`candidates_aftermarket.json`, 최대 40종목).
* `15:40 ~ 20:00`: 애프터마켓 수집 (KIS 4개 샤드, 당일 신규 주도주 대상).
